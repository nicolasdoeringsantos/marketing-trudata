# 📜 Campanha Estratégica: Reforma Tributária sem Susto — TruData

A Reforma Tributária no Brasil é uma das maiores oportunidades de posicionamento e captação de clientes para empresas de software de gestão sérias. 

Enquanto softwares caseiros, planilhas e sistemas descontinuados vão deixar seus usuários perdidos na transição para o IBS e CBS, a Hansen Software posiciona o **Trudata ERP** como a escolha segura para não sofrer penalidades fiscais.

---

## 🎯 Objetivo da Campanha
- Posicionar a Hansen Software como autoridade máxima em compliance fiscal.
- Conquistar a indicação de escritórios de contabilidade que precisam que seus clientes usem um sistema confiável.
- Atrair empresários que hoje usam sistemas defasados e temem a paralisação de suas vendas com a nova tributação.
